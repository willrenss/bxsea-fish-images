# BXSea fish images

Gambar ikan dan hewan akuatik (PNG, latar putih) untuk katalog spesies BXSea Fish ID, satu per spesies.
Dibuat dari foto iNaturalist berlisensi Creative Commons dengan nama ilmiah persis; latar dihapus otomatis
(Apple Vision, subject lifting) lalu diganti putih.
