# BXSea fish images

Gambar ikan dan hewan akuatik (PNG, latar transparan) untuk katalog spesies BXSea Fish ID, satu per spesies.
No. 1-101 dibuat dari foto iNaturalist berlisensi Creative Commons, No. 102-122 dari foto HD Wikimedia Commons
(CC BY, CC BY-SA, atau CC0) dengan latar air biru. Semua dengan nama ilmiah persis; latar dihapus otomatis
(Apple Vision, subject lifting), jadi hanya bentuk hewannya yang tersisa.
